# Jarvis - Personal AI Assistant

Jarvis is a personal assistant project built with Python, featuring a HUD interface and voice-related functionality.

## Project Files

- `jarvis.py` - Main assistant script.
- `jarvis_hud.py` - HUD-related Python script.
- `jarvis_voice.py` - Voice-related Python script.
- `hud.html` - HTML interface for the HUD.
- `.gitignore` - Excludes private and unnecessary local files from Git.

## Getting Started

1. Clone or download this repository.
2. Review the Python scripts to identify their dependencies and configuration requirements.
3. Install the required dependencies before running the project.
4. Follow the setup requirements documented in the source code.

## Privacy

Personal memory and local text files are intentionally excluded from this public repository. Never commit API keys, passwords, or private data.
